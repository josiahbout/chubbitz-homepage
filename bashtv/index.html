Getting started…

The Bash.tv website is still in alpha so they're limiting who can join, but you can get a free invite code by following the steps below.

  1. Join the Bash.tv discord server!

    Join!

  2. Go to #get-a-bash-invite, and tap “get invited to Bash.tv”
  3. Copy the invite link to your web browser and create an account!
